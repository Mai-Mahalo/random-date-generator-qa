# Random Date Generator – Manual QA Testing

## Project Overview
This repository contains manual testing documentation for the [Random Date Generator](https://codebeautify.org/generate-random-date) web application.

The purpose of this project is to evaluate the application's functionality, identify defects, and document test results.

## Testing Information
- **Testing Type:** Manual Testing
- **Browser:** Google Chrome
- **Test Cases:** 11
- **Bug Reports:** 5
- **Test Execution:** 6 Passed / 5 Failed

## Test Scope
- Page Availability
- Default and Random Date Generation
- Number of Dates
- Date Output Format
- Custom Date Format
- Date Range
- Invalid Date and Time Input

## Deliverables
- **Test Report:** Overall testing results and summary
- **Test Cases:** Test scenarios, steps, expected results, actual results, and status
- **Bug Reports:** Detailed documentation of identified defects

## Repository Structure
- `Test-Report/` – Test execution summary and results
- `Test-Cases/` – Manual test cases
- `Bug-Reports/` – Individual bug reports

## Notes
This project was conducted as a manual QA testing exercise. No automation scripts were used.
